# 吉祥物来源

## 文件

| 文件 | 用途 |
|---|---|
| `azusa-v1.png` | 主形象（深色外套版），壁纸、头像都用它 |
| `azusa-v2.png` | 备选形象（白色外套版） |

两张都是 **AI 生成的原创角色**，由用户在 2026-11 用 **OpenAI（ChatGPT）** 生成，
**不是**任何既有作品的衍生。

## 为什么这个能进 ISO

之前壁纸的死结是同人图有版权。吉祥物换成了 AI 生成的原创角色，
就不涉及第三方作品——这是发行版能合法随附它的前提。

仍有两点要注意：

1. **生成服务的条款**。这两张是 OpenAI 生成的。OpenAI 的使用条款把输出物的
   使用权交给用户（含商用），但要求你对输出内容负责，且不得用于违法用途。
   真要正式发布，请对照当时有效的 ToS 再确认一遍。
2. **风格可以相似，角色不能相似**。角色设计上如果明显照搬某个已有角色
   （换色、换服装不算原创），那仍然构成衍生。

## 生成时用的设计约束

配色来自 `branding/palette.json`：

- 银白长发、紫瞳 → `#70577f` / `#b296cc`
- 深靛外套 → `#181430`
- 星星发饰 → 呼应壁纸里的星点
- 手持 U 盘 → 「安装介质」这个系统符号

可简化为头像（`mascot-avatar-512.png`），满足做 logo 的最低要求。
