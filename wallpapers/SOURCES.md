# 壁纸来源与授权

## 结论先说

**这些壁纸只能自用，不能放进 ISO 发布。** 它们是同人作品（fanart），
版权属于各自的画师，角色版权属于 NEXON / NAT Games。
要发布系统，壁纸必须换成：自绘、画师授权、或明确允许再分发的素材。

仓库里只保存**生成脚本和来源记录**，实际的图片文件在 `dist/`（已被 gitignore）。

## 取图方式

用 Danbooru 的公开 API，**强制过滤到全年龄分级**：

```
https://danbooru.donmai.us/posts.json?tags=azusa_(blue_archive)+solo+rating:general&limit=200
```

踩过的坑：

- 不加 `rating:` 过滤会混进大量 R-18 作品，第一次就中招了；
- `width:>=1920` 这种过滤在带括号的 tag 组合里会返回空，改成在本地筛更可靠；
- 单人的横版作品极少，绝大多数是竖构图（宽高比 0.6–0.75）。

## 已生成的样例

| 输出文件 | 来源 | 处理方式 |
|---|---|---|
| `azusa-10401565-2560x1440.jpg` | Danbooru #10401565 | 圆角卡片（背景复杂，抠不干净） |

## 重新生成

```bash
./bin/azusa-wallpaper --src <图片...> --out dist/wallpapers
```

处理方式由 `--mode` 控制：

- `auto`（默认）—— 横图铺满；竖图先试抠图，失败退回圆角卡片
- `full` —— 强制铺满裁切
- `cutout` —— 强制抠图（纯色背景才靠谱）
- `card` —— 强制圆角卡片

抠图用的是「从四角泛洪填充」，只对纯色背景有效。碰到复杂背景时它会
抠出一圈白色毛边，所以默认容差压得比较保守（30），宁可退回卡片。

## 想做成能发布的壁纸，可行的路

1. **自己画 / 让 AI 画**：风格统一，授权干净
2. **只用渐变和几何**：完全避开版权，缺点是没角色
3. **找 CC0 / 明确允许再分发的画师作品**
4. **官方素材**：原作官方有时会放出壁纸，但通常也禁止商业再分发，
   个人发行版属于灰色地带

## 自己抓图

```bash
./tools/fetch-gallery.py                                  # 默认全年龄分级
./tools/fetch-gallery.py --rating general sensitive questionable explicit
```

分级由你自己传，工具不替你决定。输出的 `manifest.json` 记录每张图的
Danbooru id 和来源页，方便回头找画师。

## 关于官方 CG

官方「记忆大厅」CG 是**单人、横版、画风统一**的，比同人图更适合做壁纸，
这个判断没错。但版权上它比同人更明确地属于 NEXON / NAT Games，
所以同样只能自用、不能进 ISO。

发布版壁纸的唯一干净来源是：自己画、AI 生成**原创**内容、或 CC0 素材。
详见上面「想做成能发布的壁纸」一节。
